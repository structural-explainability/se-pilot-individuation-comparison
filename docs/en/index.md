# Individuation Comparison Pilot

This research pilot investigates whether independently documented individuation
accounts can be represented, compared, and explained without adopting either
account's assumptions as authoritative.

The pilot distinguishes mathematical comparison from scientific adequacy.
It does not establish which account is correct or define universal criteria
for individuation.

# Summit Petroleum case

**Status:** provisional retrospective illustration, not a passed adequacy test.

may permissibly inform the regulatory _adjacent properties_ requirement
for Title V source aggregation.
It is not a claim that connected facilities are one physical individual, nor that rejection of aggregation proves two completely separate units.

EPA's 2011 respondent brief is a party-authored primary source.
The Summit record in this scaffold is drawn from
how the appellate opinion **reports** Summit's position;
Summit's original filing still needs to be located and independently audited.

this creates _source/validation leakage_.
The report remains provisional.
Source and paragraph/section locators must be audited before freezing.

it is not an equivalence-class or persistence comparison.
